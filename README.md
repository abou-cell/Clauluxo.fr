# ClauLuxo Mobile

Prototype Flutter V0 de l'application mobile ClauLuxo / Centre de Luxopuncture Claudine Amerigo.

Cette version sert à valider l'ergonomie et le parcours de prise de rendez-vous avant connexion aux services en ligne.


## Clauluxo V1 / Firebase Deployment

La branche `clauluxo-v1-content` contient la mise à jour gratuite du contenu, des assets et la documentation de préparation. Firebase et toute facturation restent désactivés jusqu’à validation explicite.


## Prototype Firebase Spark

Le prototype est préparé sur la branche `clauluxo-prototype-spark`. Il reste volontairement sans facturation, sans Storage et sans identifiants Firebase inventés.
